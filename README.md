# School Related Project
## Website for a student council representative.
Task was to create a website for a student council representative candidate in the style of a political party PR campaign. This was the website project among the posters and other things created. 

## Stack
This project used Next.JS and TailwindCSS written in TS. 

This type of website should have been done in something like Astro since it's static but that is something I'm not fully confident in and needed to ship a product instead.

# Design choices

The candidate gave me two color codes to work with. The strong purple color is one of them and the rest of the website was instructed to be white or with pastel colors related to purple.
I went for a big modern hero section to catch the readers attention and to give a first impression as to what the candidate stands for. Other sections were separated into smaller bits and cards to make the information easier to consume for the visitor. The about page was made interactive with a video, short text and an image stack. This way the user is more engaged if they are prompted to listen or to click on something. Adding such small interactions has a huge impact and leaves a stronger impression.

# Tools
This project was made with assistance of AI as a minor section editor while I worked on other parts of the page. Models used were Sol 5.6 and Mimo 2.5 Pro.
